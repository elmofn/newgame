# O Intervalo — playtest 003

Protótipo de ação isométrica para testes em navegador de desktop.

## Controles

- WASD / setas: mover
- Mouse: mirar; clique ou segurar: atirar
- Espaço / E: alternar dimensão
- F: entrar pela porta liberada
- Esc: pausar
- R: reiniciar a partida

Na matéria, os tiros criam fraturas; no espírito, o próximo acerto detona as marcas. Permanecer no espírito acumula pressão e cria novos perigos.

Esta branch contém a versão estática para hospedagem. O arquivo index.html é independente de serviços externos.

Para ativar no GitHub: Settings > Pages > Deploy from a branch > gh-pages > / (root) > Save.
